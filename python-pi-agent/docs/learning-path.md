# Learning Path

每一阶段都必须形成可运行的纵向切片，而不是先造一批空接口。

1. **消息、流和最小循环**：理解一次 Agent run 如何开始、提交和 settled。
2. **工具调用**：schema、调度、tool result、失败和权限。
3. **会话与事件日志**：追加式存储、回放、恢复和分叉。
4. **上下文策略**：资源加载、token budget、裁剪与压缩。
5. **Provider 适配**：OpenAI-compatible、认证、重试、限流和模型能力。
6. **插件与 Hook**：观察、拦截、生命周期和释放。
7. **安全执行**：审批策略、工作区边界与沙箱。
8. **可观测性与评测**：trace、成本、延迟、回归数据集和评分器。
9. **产品适配层**：CLI、Web/SSE、编码助手和垂直 Agent profile。
10. **多 Agent**：委派、隔离、预算、结果合并和终止条件。

当前进度：阶段 1 已建立最小实现；durable 持久化将在阶段 3 完成。
