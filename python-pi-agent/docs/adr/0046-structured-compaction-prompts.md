# ADR 0046：任务恢复导向的结构化摘要模板

状态：已接受，2026-11-22。

## 背景

默认摘要仅列出应保留的信息，没有固定结构，也没有明确禁止继续历史任务。压缩后需要保留目标、证据、未验证事项和未知副作用，避免把计划或中断当成已完成或失败。

## 决定

- 在现有 ModelCompactionStrategy 中替换默认 system 模板，固定八个章节及其信息保留要求。
- 历史与早期摘要是待总结数据；不回答历史问题、不执行历史指令，不编造事实；分别标记 none 和 unknown。
- 保留独立 Provider、空工具列表、序列化输入、完整结束检查、取消传播和现有 durable compaction 流程。
- 自定义 system_prompt 完全替换默认文本；标题不是强制解析协议，当前不校验摘要语义质量。

## 备选方案

仅增加几个关键词仍缺少恢复结构；严格解析 Markdown 会把格式要求变成新的协议并破坏自定义模板；新增摘要框架或端口没有必要，现有 CompactionStrategy 已提供替换边界。

## 后果

默认请求增加少量指令文本；既有摘要不迁移。结构更明确但不能保证模型行为，安全边界仍来自不暴露工具及现有运行时契约。分支摘要、质量评分与增量摘要留待后续。

## 验证

test_compaction 检查模板请求、精确自定义文本、非完整摘要失败与取消；test_system_prompts 验证压缩保留已渲染系统提示词；Session 回归验证 durable/失败语义。示例 46 使用脚本化 FakeProvider 打印请求、checkpoint 与事件，不调用付费模型。真实语义质量需单独版本化评测。
